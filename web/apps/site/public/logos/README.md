# Logo 资源说明

本站 UI 通过 npm 包 [`simple-icons`](https://simpleicons.org) 渲染官方品牌 SVG（CC0），对应图标：

| 语言 | simple-icons slug | 官方品牌页 |
|------|-------------------|------------|
| Go | `go` | https://go.dev/blog/go-brand |
| Node.js | `nodedotjs` | https://nodejs.org/en/about/branding |

也可从 simple-icons CDN 直接下载 SVG：

- Go: https://cdn.jsdelivr.net/npm/simple-icons@v16/icons/go.svg
- Node.js: https://cdn.jsdelivr.net/npm/simple-icons@v16/icons/nodedotjs.svg

Go 完整品牌包（含 Gopher）：https://go.dev/s/logos
